EmiLife — Modern Life OS

EmiLife est une application de productivité personnelle pour organiser ses projets, ses tâches, ses habitudes, ses finances et ses objectifs quotidiens.

Fonctionnalités

- Cockpit : tableau de bord et minuteur Pomodoro.
- Projets et tâches : ajouter, terminer et supprimer des tâches.
- Habitudes : suivre ses validations quotidiennes.
- Finances : enregistrer revenus et dépenses en FCFA.
- Bilan quotidien : noter ses victoires, ses obstacles et ses priorités pour demain.
- Interface responsive : utilisation sur téléphone, tablette et ordinateur.
- Stockage local : les données de cette version sont enregistrées dans le navigateur de l'utilisateur.

Installation

Cette version est une page HTML autonome. Pour la tester, ouvre "Index.html" dans un navigateur compatible.

Pour un déploiement web classique, configure un hébergement adapté et vérifie que les chemins des ressources sont corrects.

Évolutions prévues

- Authentification sécurisée.
- Synchronisation des données avec Supabase.
- Base de données PostgreSQL avec règles RLS.
- Installation PWA améliorée.
- Préparation d'une application Android installable.

Sécurité

Ne place aucune clé secrète, aucun mot de passe ni fichier ".env" contenant des secrets dans le dépôt.
